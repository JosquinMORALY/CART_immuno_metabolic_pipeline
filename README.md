## Overview

This repository contains the processed data and analysis code used to generate **Figure 1** and **Extended Data Figure 1**.

The immuno-metabolic CAR T-cell profiling pipeline combines longitudinal measurement of 12 cytokines and chemokines over 72 hours using the IMMUNOtron robotic pipeline developed by Grégoire Altan-Bonnet and colleagues at the National Cancer Institute (NCI) [1], with high-dimensional spectral flow cytometry and metabolic measurements following activation with antigen-expressing NALM6 cell lines. Metabolic profiling includes extracellular acidification rate (ECAR), oxygen consumption rate (OCR), spare respiratory capacity (SRC), protein synthesis, mitochondrial mass, membrane potential, mitochondrial ROS, and GLUT1 and ASCT2 surface expression measured using receptor-binding domains (Metafora Biosystems) [2].
